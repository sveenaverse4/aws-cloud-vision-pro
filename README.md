Cloud Vision Pro: Automated Image Management
This project demonstrates a secure, scalable solution for handling media uploads using AWS S3.

What this does:
Storage: Securely stores images in S3 buckets.

Automation: Configured via AWS CLI for rapid deployment.

Scalability: Built to handle thousands of concurrent uploads with high availability.

Technical Skills Shown:
Identity & Access Management (IAM): Implementing the principle of least privilege for bucket access.

AWS CLI: Automating cloud resource management.

S3 Configuration: Setting up bucket policies and public/private access controls.
